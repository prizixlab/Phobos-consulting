User Permissions

Define what each role can access. Use presets or build a custom role with granular feature control.

visibility

Viewer

Read-only access to the platform. Can view dashboards, container lists, movement logs, and analytics but cannot make any changes, export data, or access settings. Ideal for executives or external partners who need visibility without operational control.

engineering

Operator

Full operational access. Can view all data, export CSVs, edit container details, add movement log entries, and manage daily yard operations. Cannot access system settings, integrations, or user management. Designed for yard staff and operations managers.

admin_panel_settings

Admin

Unrestricted access to all features. Can manage users, configure integrations, change system settings, build yard layouts, and modify permissions. Should only be assigned to trusted team leads or system administrators.
